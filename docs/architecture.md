## Компоненты

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Оркестрация | n8n | Управление пайплайном |
| Источник 1 | Хабр RSS | Вакансии из IT-сферы |
| Источник 2 | HH API | Основной источник вакансий |
| Фильтрация | n8n Filter | Отбор по опыту и формату |
| Ранжирование | JavaScript (Code) | Взвешенный скоринг |
| Хранение | Docker volumes | Данные n8n |
| Уведомления | Telegram API | Дайджест |

## Ключевые решения

1. **Параллельный сбор** — два источника обрабатываются независимо
2. **Единый формат** — после парсинга оба источника приводятся к одинаковой структуре
3. **Взвешенный скоринг** — совпадения в названии важнее, чем в описании
4. **Markdown (Legacy)** — стабильное форматирование без экранирования
