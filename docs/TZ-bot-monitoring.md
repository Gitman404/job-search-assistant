# ТЗ: Telegram-бот для мониторинга вакансий (на базе n8n)

## Цель
Автоматизировать первичный поиск вакансий, чтобы ежедневно получать подборку самых релевантных вариантов, не тратя время на ручной просмотр десятков страниц.

## Критерии отбора (что ищем)
Бот должен фильтровать вакансии по следующим параметрам (учитывая, что не все могут быть в явном виде в структуре данных — будем использовать поиск по ключевым словам в тексте):
*   **Название вакансии:** «помощник project», «младший менеджер проектов», «стажёр project», «менеджер проектов», «project manager», «помощник менеджера проектов».
*   **Опыт работы:** «Не требуется» или «Начальный» (либо явное упоминание в тексте).
*   **Формат работы:** «Удалённо» или «Гибрид»/«Смешанный» (Москва также допустима как запасной вариант).
*   **Ключевые навыки в описании (дополнительный плюс):** упоминание ИИ, нейросетей, no-code, автоматизации, проектирования, оптимизации процессов.

## Алгоритм работы бота (логика)
1.  **Сбор:** Раз в день (например, в 9:00) бот парсит заданные источники по RSS или через (неофициальные) API.
2.  **Фильтрация:** Применяет фильтры по ключевым словам (из п. «Критерии»).
3.  **Ранжирование:** Из всех найденных вакансий выбирает **5 самых релевантных** (тех, где совпало больше всего критериев, или где есть явные упоминания ИИ/автоматизации).
4.  **Формирование дайджеста:** Создаёт сообщение в Telegram со списком вакансий. Для каждой:
    *   Название вакансии.
    *   Компания.
    *   Краткое описание (первые 1-2 предложения или ключевые требования).
    *   Ссылка на полную вакансию.
    *   (Опционально) Почему бот выбрал эту вакансию (совпавшие критерии).
5.  **Отправка:** Отправляет готовый дайджест в собственный Telegram-чат пользователю.

## Технические ограничения
*   Платформа: **n8n** (бесплатный облачный тариф или self-hosted, если потребуется).
*   Бюджет: минимальный (бесплатные квоты, API без оплаты).
*   Язык: не требуется, всё делается в визуальном редакторе n8n.

## Что делать с результатом
Полученные в Telegram вакансии пользователь вручную добавляет в свою систему (Гугл-таблицу статусов) и решает, по каким откликаться. Бот — это фильтр первичного шума.

«Я хочу создать такого бота в n8n. С чего начать? Опиши пошаговую инструкцию для новичка: какие узлы (nodes) использовать, как настроить парсинг RSS Хабр Карьеры, как добавить фильтрацию по ключевым словам, как отправить результат в Telegram».
