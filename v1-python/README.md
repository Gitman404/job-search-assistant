## Бот для мониторинга вакансий — версия 1.0 (Python)

### Зачем

Пет‑проект, который демонстрирует навык **проектирования ассистентов/ботов** и автоматизации: бот ежедневно находит вакансии, фильтрует “шум”, сохраняет результат в Obsidian как базу знаний и отправляет дайджест в Telegram.

### Pitch

Я сделал бота‑ассистента для мониторинга вакансий как пет‑проект под карьерный трек. Он решает практическую задачу: не тратить время на ручной просмотр сотен вакансий и при этом сохранять найденное в удобную базу знаний.

Технически это пайплайн: коннектор к HH API → фильтрация по целевым ролям и опыту → доменная фильтрация (например, отсекаю “строительные проекты”, даже если в названии есть слово “проект”) → скоринг релевантности с объяснением “почему выбрано” → сохранение результатов в Obsidian в виде структурированных `.md` заметок. Сверху есть Telegram‑витрина: командой `/run` можно запустить сбор и получить топ‑5 с ссылками.

В итоге у меня получился мини‑продукт: **данные попадают в систему управления (Obsidian), а не теряются в чате**, при этом остаётся быстрый канал уведомлений (Telegram). Дальше план — добавить планировщик, второй источник (Habr Career) и деплой в Docker/VPS.

### Что умеет сейчас

- **Сбор вакансий с HH** через публичный API.
- **Фильтрация по целевым ролям** (junior/assistant/стажёр project, администратор/координатор проекта).
- **Фильтр по сфере** (исключает строительство/девелопмент по “доменным” словам в тексте).
- **Скоринг релевантности** (`matchScore`) + объяснение “почему выбрано ботом”.
- **Дедупликация** (не создаёт дубли при повторном запуске).
- **Создание заметок в Obsidian** в папке вакансий.
- **Telegram‑бот (витрина)**: команда `/run` запускает пайплайн и присылает топ‑5.

### Архитектура (что было спроектировано)

1) Коннектор источника (HH) → список вакансий  
2) Фильтры + скоринг → отбор релевантных  
3) Запись в Obsidian (`.md` + YAML) → дашборды Dataview  
4) Telegram‑слой → уведомления и “кнопка запуска”

Telegram (команда /run)  
│  
▼  
run_hh_to_obsidian.py  
│  
├──► HH API (поиск вакансий)  
├──► Фильтрация (роли, опыт, доменные слова)  
├──► Скоринг (matchScore)  
├──► Дедупликация (state.json)  
│  
▼  
Obsidian (заметка в папке вакансий)  
│  
▼  
Telegram (дайджест топ-5)
